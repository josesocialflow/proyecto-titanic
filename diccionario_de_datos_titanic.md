# Diccionario de Datos: Titanic CSV

| Columna en inglés | Traducción al español | Descripción y significado |
| :--- | :--- | :--- |
| **PassengerId** | ID del pasajero | Número identificador único asignado a cada pasajero (del 1 al 891). |
| **Survived** | Sobrevivió | Indica si la persona sobrevivió al naufragio.<br>• **0** = No sobrevivió (Falleció)<br>• **1** = Sí sobrevivió |
| **Pclass** | Clase de pasaje | Clase socioeconómica en la que viajaba el pasajero.<br>• **1** = Primera clase (Alta)<br>• **2** = Segunda clase (Media)<br>• **3** = Tercera clase (Baja / Steerage) |
| **Name** | Nombre | Nombre completo del pasajero (suele incluir el título como Mr., Mrs., Miss, Master, etc.). |
| **Sex** | Género | Sexo del pasajero (`male` = hombre, `female` = mujer). |
| **Age** | Edad | Edad del pasajero en años. (Para bebés menores de 1 año, aparece como un valor decimal). |
| **SibSp** | Hermanos / Cónyuges a bordo | Cantidad de hermanos (*Siblings*) o esposos/as (*Spouse*) que acompañaban al pasajero en el barco. |
| **Parch** | Padres / Hijos a bordo | Cantidad de padres (*Parents*) o hijos/as (*Children*) que acompañaban al pasajero en el barco. |
| **Ticket** | Número de boleto | Código o número identificador del billete o pasaje comprado. |
| **Fare** | Tarifa / Precio del pasaje | Precio o cantidad de dinero pagada por el billete (en libras esterlinas de la época). |
| **Cabin** | Número de camarote | Código de la cabina asignada (ejemplo: C85). Contiene muchos valores nulos (`NaN`). |
| **Embarked** | Puerto de embarque | Puerto donde el pasajero abordó el Titanic.<br>• **C** = Cherburgo (Francia)<br>• **Q** = Queenstown (Irlanda)<br>• **S** = Southampton (Inglaterra) |
